For this option, your team should produce an application that shows restaurants in Newcastle. Users should be able to see what open restaurants are nearby (i.e., maximum radius of 1 mile from their current location) by using a map as well as an option to show restaurants nearby as a list. 

**Basic Requirements** 
The implemented system should have the following functionality 
	• Show open restaurants within a 1 mile radius using a map view as well as a list. 
	• Allow the user to filter what restaurants displayed by cuisine (I.e., American, British, Chinese, Indian, Italian, etc.) 
	• When the user selects a particular restaurant, display: 
		o How far (in yards or metres) the restaurant is from the user’s current location 
		o Links to online photos of the restaurant 
		o Information of opening times (if applicable) 
		o Average cost of a main course dish 
		o Approximate walking times 
		These requirements should be refined into a set of deliverables by your team. It is expected that teams will deliver all basic requirements. 
	Assumptions 
		• While the application is focused on Newcastle, it should be easy to adapt for another city or location. 
		• The app should be optimised for mobile phones. • The app will show at least one picture of each restaurant. 
	Possible Extensions You may want to consider some extensions, for example: 
		• Display additional information regarding allergies and dietary preferences for each restaurant (I.e., offers gluten free, offers vegan options etc.) 
		• Allow users to leave reviews of each restaurant and allow other users of the same application to see the reviews. 
		• Allow users to share where they are on various social platforms. Your team can add other extensions if they like, however please check with Dan or John if the proposed extensions are suitable before starting to implement them
